## 1. 要解决的问题

玩家说「闭关十年」时，必须真的过十年、真的变老，而不是 AI 写「瞬息十年」却不扣月。气血归零或寿元耗尽后，不得再调模型、不得再加修为。

玩家会累：一句「聊聊天」过几个时辰说得通；一句「我回答了好的」不得偷走一天，更不得记成一个月。玩家推剧情时多半只点开一场或写个大概，天道应把这场戏推完（时间按**这场**算）；若拆成一句一句，天道接同一场，钟几乎不走。

## 3. 实体与字段

标识符与库表一致，禁止另起中文拼音字段。

**修士（`players`）**

| 字段 | 含义 | 默认 / 夹紧 |
|------|------|-------------|
| `hp` / `max_hp` | 气血 | 开局 100；增减后夹在 `[0, max_hp]` |
| `mp` / `max_mp` | 灵力 | 同上；本册不另写回复公式，走行动增量 |
| `cultivation` | 修为 | 下限 0，无数字上限（门槛在境界表） |
| `age` | 虚岁（整数年） | 开局 **16** |
| `pending_months` | **修士**未满一年的零碎月 | 满 12 进 1 岁，余数保留 4 位小数 |
| `max_lifespan` | 寿元上限（年） | 开局 **100**；大境突破成功由法则表覆盖 |

**存档（`saves`）**

| 字段 | 含义 |
|------|------|
| `is_game_over` | 本回合结算已死后为真；死亡锁读此旗 **或** 当场气血/寿元判定 |
| `in_samsara_pool` | 死后是否入轮回池；资格见 **I27**，本册不写遗泽 |

**世界（`world_state`）— 已有**

| 字段 | 含义 |
|------|------|
| `current_year` | 天玄历年，开局 **387** |
| `current_season` | `春` / `夏` / `秋` / `冬`，开局春 |
| `pending_months` | **世界**未满一季（3 个月）的零碎月；与修士 `pending_months` **不是同一列** |

情境锁 `scene_context`、A6 近事列见 [situation.md](./situation.md)、[chronicle.md](./chronicle.md)，**不要**把谈话场塞进 `scene_context`（仍只有 `none \| combat`）。

**世界 — 加深新增（英文标识符，已建列）**

| 列 | 取值 | 说明 |
|----|------|------|
| `day_phase` | `dawn` / `noon` / `dusk` / `night` | 给玩家看的调度：晨 / 午 / 晚 / 夜。缺省 `dawn` |
| `pending_shichen` | 整数 0～2 | 当前日段内已过的时辰（一段 3 时辰；满 3 换段） |
| `pending_days` | 整数 0～29 | 本月已过的整日；满 30 进 1 月，写入修士/世界 `pending_months`。时辰太碎，**禁止**只用现有四位小数月去记 1 时辰 |
| `beat_scene` | `none` / `talk` / `market` | 未收束的微行场。与 A6 `pending_scene`（奇遇）分开，禁止混用 |

内部换算：1 日 = **12 时辰**；1 日段 = **3 时辰**；30 日 = 1 月（与现有「天/30」闭关解析一致）。界面主展示年与季，日段次之；不必把子丑寅卯写上状态卡。

落点与开工顺序见 [player_state_architecture.md](./player_state_architecture.md)。

## 4. 资源夹紧

- `clampResource(current, delta, max)`：气血、灵力；不得为负、不得超上限。
- `applyCultivationDelta(current, delta)`：修为只保 ≥0。
- 突破成功时修为 **清零**（小境与大境皆然），由 `resolveBreakthroughAttempt` 的 `patch` 覆盖，不走 `cultivation_delta`。

**本回合气血谁说了算**（`ActionService`，自上而下只走一条）：

1. 本回合走了突破拦截器 → 用突破 `patch.hp`
2. 否则天罚触发 → 天罚 `patch.hp`
3. 否则高危地图 → 按上限百分比扣
4. 否则双修成功 → 双修回复
5. 否则战斗公式 → 含秒杀归零
6. 否则才采信 AI 的 `hp_delta`

灵力：双修成功走双修回复，否则 `mp_delta`。  
修为：突破 / 天罚 / **闭关公式** / 双修 / 否则 `cultivation_delta`。闭关与突破同回不叠：有突破结果则不算闭关修为。

## 5. 时间档

分清 **现码** 与 **加深后铁律**，禁止两套同时当权威。

### 5.0 现码（未加深前以代码为准）

优先级（成功回合）：

```
monthsPassed = 闭关月数 ?? 炼制月数 ?? (AI.time_cost_months || 1)
```

- 句中有「闭关」→ `detectSeclusionMonths`，AI 月数作废。
- 否则命中炼制 → 用配方月数。
- 否则用模型给的月数；**缺省或 0 则记 1 月**（闲聊漏填会被记成历练一个月）。

旧白皮书「对话 0.1～0.2 月」约合三到六天，比「过一天」更狠，**已废**，以第 5.4 节为准。

禁止：AI 叙事「瞬息十年」而闭关路径不扣月——现码闭关已堵。

### 5.1 闭关解析（`detectSeclusionMonths`，现码已有）

- 无「闭关」→ `null`。
- 「半年 / 半载」→ 6 月。
- `数字+(年|载)` → 年×12（阿拉伯或中文，解析见 `numeral.ts`）。
- `数字+个?月` → 月。
- `数字+(天|日)` → 天/30，四舍五入到 4 位小数。
- 有「闭关」但未写时长 → **默认 12 月**（一年）。
- 战中闭关：情境锁 **400**，本函数不会跑到加修为；见 [situation.md](./situation.md)。
- 加深后：闭关 **跳过日段**，出关落到 `dawn`；叙事仍「山中无甲子」，禁止写成子时到卯时流水账。

`describeMonths` 只为拼 `forcedOutcome`（如「10年」），不单独落库。加深后微行展示用「片刻 / 一时辰 / 晨转午」，不要对 0 时辰写「流逝 0 个月」。

### 5.2 年龄（`advanceAge`）

`pending_months + monthsPassed`，满 12 月 `age += 1`，余数写回修士 `pending_months`。闭关十年（120 月）一次进 10 岁。加深后：时辰先合成日、日合成月，再进入本函数；不要用时辰直接加 `age`。

### 5.3 天玄历（`advanceWorldTime`）

每满 **3** 月推一季：春→夏→秋→冬→下一年春。世界 `pending_months` 与修士列独立累加，但 **同一笔「已折算的月」** 同时推进两边。前端「天玄历」展示年来自 `GET /api/player/:id` 的 `current_year` / `current_season`；加深后附 `day_phase`。

NPC 是否同期变老：人际系统用投影年份查仙逝，属 **I16**；本册只保证世界年会走。

### 5.4 加深决议：日段、时辰、按场扣时（词表已封口，代码已落地）

**主钟仍是年 / 季 / 月。** 时辰只做微行累加器。点名「亥时动手」只把叙事锁到该日段，**不加时辰、不改主钟为十二时辰表**。

**日段调度（给玩家看）**

| `day_phase` | 文案 | 适合 |
|-------------|------|------|
| `dawn` | 晨 | 出关、上路默认 |
| `noon` | 午 | 坊市、叙话 |
| `dusk` | 晚 | 回府、酒宴 |
| `night` | 夜 | 偷营、子时开阵（点名才强调） |

满 3 时辰：`dawn`→`noon`→`dusk`→`night`→`pending_days += 1` 并回到 `dawn`（`pending_shichen = 0`）。`pending_days` 满 30 → 两边 `pending_months` 各 +1，日清零。一夜未眠用日段停在 `night` 的叙事，**不扣精力条**。

**按场，不按字数。** 禁止句子长度、禁止第二次 LLM 分类「细/粗」。匹配一律 `includes` 明文子串，禁止正则。

#### 5.4.1 判定优先级（自上而下只走一档）

对净化后的行动文本，**先命中先停**：

1. 含「闭关」→ 走现有 `detectSeclusionMonths`；`beat_scene = none`；日段重置 `dawn`，`pending_shichen = 0`（不累加微行时辰）。月数仍由闭关解析。
2. 否则本回合命中炼制拦截器 → 用配方 `craftMonths` 进月；`beat_scene = none`。
3. 否则命中 **历练/交手** 表 → **1 月**；`beat_scene = none`；日段落到 `dusk`（跳过微行时辰）。
4. 否则 `beat_scene` 已是 `talk` 或 `market`：
   - 命中 **离开** 表 → `none`；含「回府」则日段落到 `dusk`；本回合 **0 时辰**。
   - 否则（场内词、同场再点开场词、或未列表的一句接话）→ **0 时辰**，场不变。
5. 否则 `beat_scene === none`：
   - 命中 **坊市开场** 表 → 置 `market`，扣开场时辰。
   - 否则命中 **叙话开场** 表 → 置 `talk`，扣开场时辰。
   - 否则 **未命中档** → **1 时辰**，场仍为 `none`。禁止回退到模型的 `time_cost_months`，禁止再默认 1 月。

同句既有「历练」又有「聊聊天」：第 3 档已停，按 1 月。同句坊市词与叙话词都有：第 5 档 **坊市优先**。

#### 5.4.2 开场时辰（1～2 日段）

开场扣 **3 或 6 时辰**（1 或 2 日段），不得一天（12 时辰）。

```
openingShichen(rollFn) = rollFn() < 0.5 ? 3 : 6
```

单测：`() => 0` → 3；`() => 0.99` → 6。禁止 `Math.random()` 写死在拦截器里。

已在同场再点开场词：走第 4 档，**不**再掷 3～6。

#### 5.4.3 封闭词表（只准改本表，不准实现时再猜）

**叙话开场 → `talk`**

`聊聊天`、`叙话`、`闲谈`、`闲聊`、`一席酒`、`喝一杯`、`攀谈`、`交谈`、`说说话`、`打听修仙门路`

`逛逛坊市`、`去坊市`、`在坊市`、`坊市四处转转`、`逛街`、`逛一逛`

**场内细推（0 时辰；仅当已在 `talk`/`market` 时单独点名；未在场时这些句走未命中档 1 时辰）**

`我说好的`、`好的`、`点点头`、`点头`、`回答了一句`、`答了一句`、`嗯`、`诺`、`领命`、`是`

**离开 → `beat_scene = none`（与 A6 离开表对齐，不含探索「不算离开」词）**

`不管他`、`弃之不顾`、`抛下`、`丢下`、`告辞`、`就此别过`、`转身离去`、`离开此地`、`回府`

## 6. 寿元与大限

- **坐化条件**：`age > max_lifespan`（**等于上限仍活着**）。
- 剩余年：`max(0, max_lifespan - age)`。
- **大限预警**：剩余年 > 0 且 ≤ 阈值。阈值 = `clamp(round(max_lifespan × 10%), 3, 50)` 年。已坐化（剩余 0）不再预警，直接死亡。
- 预警句写入 `forcedOutcome`（「寿元仅剩 N 年，大限将至」），前端状态卡用 `lifespanStatus` 标剩余年。
- 寿元上限只由大境突破成功的 `newLifespan` 等拦截器改写，禁止 AI JSON 改 `max_lifespan`。

## 7. 死亡与死亡锁

### 7.1 死因（`DeathReason`）

本回合结算后 **一条** 原因，优先级：

1. 渡劫当场轰灭 → `tribulation_failure`
2. 天罚致命 → `karma_retribution`
3. 禁地去之即死 → `region_danger`
4. 境界压制秒杀 → `realm_suppression`
5. 否则 `getDeathReason`：`hp <= 0` → `hp_exhausted`；否则寿元耗尽 → `lifespan_exhausted`

气血与寿元同时烂掉时，基础函数 **先报气血**。

### 7.2 死亡锁（在调模型、占日限之前）

`ActionService.execute` 查到玩家后立刻：

`saves.is_game_over` **或** `getDeathReason(hp, age, max_lifespan) !== null`

→ **403**，文案：「大限已至，道消身陨，万事皆休。」不占日限、不调 DeepSeek、不改库。

死亡锁 **不在** 网关目录里，见 [player_agency.md](./player_agency.md) 第 7 节。

本回合才死：事务里把 `is_game_over = true`；若境界够格则 `in_samsara_pool`（**I27**）。前端日志按死因换短讯（无 emoji）。局内输入在 `hp<=0` 或 `age > max_lifespan` 时禁用。

读档回滚可清死亡态，属 **I27**；规格要求死后仍能开读档，现状缺口见进度表 S16（按钮仍可能被灰掉），不在本册改 UI。

## 8. 调用顺序（只写本册相关）

与 [player_agency.md](./player_agency.md) 第 7 节同一条河，此处不重复网关。

1. 查修士；**死亡锁 403**
2. 情境锁（可能 400）
3. 日限
4. 突破拦截器（可能改本回合寿元上限，供预警使用）
5. ……其余拦截器；有「闭关」则解析月数并算闭关修为（无洞府则借地，**I17**）
6. 调 AI（现码：`time_cost_months` 仅非闭关、非炼制时可能被用；加深后微行月数由日段/时辰折算，**不采信**模型填的月）
7. 战斗公式覆盖气血
8. `monthsPassed` → `advanceAge` + `advanceWorldTime`（加深后先结算时辰/日段）
9. 死因 → 可能写 `is_game_over`
10. 快照（含 `world_state`）

禁止先让模型报「你已坐化」再由后端改年龄。

## 9. 铁律

- 禁止采信模型返回的气血/修为/寿元/胜负去覆盖第 4 节结算链。
- 禁止用 prompt 代替死亡锁或闭关月数解析。

## 10. 本阶段加深（已落地）

只补岁月体感与死亡体验，不开新系统、不做生存条。

1. **按场硬锁微行（第 5.4 节）**：开场子串 1～2 日段；场内「好的」0 时辰；离开清 `beat_scene`。可测：「继续前行」类不在本表（那是 A6）。「与掌柜闲聊」不得 `monthsPassed === 1`。「我回答了一句好的」且已在 `talk` → 0 时辰、日段不变。

## 11. 验收

**现码**（`playerState.service.test.ts`，不测真实 LLM）：

- 60 次 0.2 月 → 年龄 +1，pending 归零。
- 闭关十年 → 120 月、年龄 +10。
- 「闭关十年」解析 120；无时长默认 12；无「闭关」得 `null`。
- `age === max_lifespan` 未死；`age > max_lifespan` 为 `lifespan_exhausted`。
- `hp === 0` 为 `hp_exhausted`，优先于寿元。
- 大限：上限 100、剩余 8 年触发预警；剩余 0 不预警。
- 世界：冬再过 3 月 → 年 +1、春。
- 手动：死后再行动 → 403，无新叙事。

**加深落地后的单测**（已补在 `playerState.service.test.ts`，固定句 + 注入 `rollFn`）：

- `beat_scene=none` +「聊聊天」+ `rollFn → 0` → `talk`，+3 时辰，`monthsPassed === 0`。
- 同上 + `rollFn → 0.99` → +6 时辰，仍不得进 1 月。
- 已 `talk` +「聊聊天」→ 0 时辰（不连刷）。
- 已 `talk` +「我回答了一句好的」→ 0 时辰，日段不变。
- 已 `talk` +「告辞，回府」→ `beat_scene=none`，日段 `dusk`。
- `none` +「搜寻机缘」→ 1 时辰，不是 1 月。
- `none` +「前往青岳山外历练」→ 1 月。
- 满 3 时辰换段；`night` 再满 3 → `pending_days +1`、`dawn`。
- 不调用第二次 LLM。
