# S20 功法与神通构筑（规格）

规格先行，代码未写。数值仍由后端硬算；AI 只描写招式名与场面。铁律见 [game_design.md](./game_design.md)。依赖现有：闭关公式功法系数占位 1.0、`combat.service.ts` 境界压制、背包物品。

---

## 1. 要解决的问题

现在战斗是境界差 + 天赋/命格乘数 + 叙事。玩家没有「主修哪本功、这一招耗多少灵力」。本系统让构筑进入公式，替换功法系数 1.0。

---

## 2. 核心实体

| 实体 | 一句话 |
|------|--------|
| 功法 | 可装备的修炼法门，有品阶与灵根契合 |
| 功法槽 | 每存档 1 主修 + 2 辅修 |
| 招式 | 普攻 / 绝技 / 身法 / 神通 四种槽位技能 |
| 残卷 | 背包物品，参悟后可能得到功法或招式 |
| 参悟尝试 | 一次消耗时间与悟性的硬结算 |
| 战斗指令 | 本回合选用的招式（或默认普攻） |

---

## 3. 字段（无代码）

**功法**

- 标识、名称、品阶（黄/玄/地/天，暂定）
- 主属灵根（金木水火土或无）
- 主修时的功法系数（建议黄 0.9、玄 1.1、地 1.25、天 1.45；未装备 = 1.0）
- 辅修词条：如火系增伤、闭关回血百分比（只生效已装备的辅修）
- 最低境界（未达则不能装备）

**功法槽**

- 主修功法 id 或空
- 辅修 1、辅修 2（可空）
- 替换：卸下旧主修进背包，不销毁

**招式**

- 类型：普攻（低耗）、绝技（高耗、高伤）、身法（影响闪避/先手，不直接改境界差秒杀规则）、神通（大冷却或一次性）
- 灵力消耗、冷却（以「行动次数」计，不由 AI 编）
- 伤害乘数（乘在现有战斗输出上，**不能**绕过差两大境秒杀）

**残卷 / 参悟**

- 残卷 id、对应可能产出、悟性门槛、基础耗时（月）
- 失败：概率毁卷（建议悟性低于门槛时失败率升高，最低仍保留小概率成功）

---

## 4. 边界与铁律

- 功法系数只进闭关修炼公式与（可选）日常小额修为；不让 AI 填写 `cultivation_delta` 代替公式。
- 差两大境秒杀、差一大境 40% 输出规则 **不可** 被神通取消。
- 未识别招式名 → 按普攻。
- **未习任何招式时**，玩家声称「法术 / 术法 / 神通 / 某系法术」→ 拦截器落空（`technique.service.ts`），叙事不得让术成真。S20 接入已知招式名表后，命中已学之名可放过。
- 残卷不在字典内 → 不当成功参悟。
- UI：状态栏显示主修名；选项里可出现〔绝技〕〔身法〕标签。剧情禁 emoji。

---

## 5. 与现有系统的衔接

- 背包：功法/残卷为物品或独立表（实现时二选一，推荐独立表 + 背包只存残卷，避免物品字典膨胀）。
- 天赋乘数：与功法乘数相乘。
- 灵根：主修灵根与玩家灵根无交集时，功法系数打 0.85 惩罚（暂定）。

---

## 6. 暂定决议（实现前可改，改则更新本文件）

1. 槽位固定 1+2，不做第三辅修。
2. 第一期招式库 8～15 条即可，与内容表同期扩充。
3. 不在第一期做「双修功法冲突炸死」；只做不能装备两本同名。

---

## 7. 开放问题

- 神通是否允许「一次性改命」类效果（建议不做，避免破坏功德/雷劫）。
- 功法是否可升级（参悟同一本多次）还是只换本。

---

## 8. 验收

- 装备黄阶主修后，同等闭关修为低于玄阶。
- 绝技扣 MP，MP 不足自动普攻。
- 单测覆盖：系数、槽位替换、参悟成功/毁卷、招式不能破秒杀。
