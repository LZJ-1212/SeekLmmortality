## 1. 要解决的问题

面板上有资质、悟性、神识、遁速、道心、仙缘。玩家要知道各自进哪条公式，而不是「看起来都像战斗力」。气运尤其容易误解成「运气差就摊更多祸」——**现码不是这样**。

创角选项必须能对上命格表：前端有、后端当未知丢掉，等于白选。

## 3. 六维总表（唯一）

字段与 `players` 表一致。中位 **10**。创角滑条合计 **60** 点（六维皆 10 时剩 0）。

**夹紧有两道，不要混：**

| 时机 | 夹 |
|------|-----|
| 创角写入（含命格加成、轮回属性遗泽） | **1～20**（`characterCreation.service`） |
| 交手三维（攻/防/速） | **1～15**（`clampCombatStat`） |

面板可以高于 15；打人时攻防速仍按 15 封顶。资质、悟性、仙缘交手不读，不受这道 15 限制。

| 中文 | 字段 | 现码干什么 | 公式写在哪 |
|------|------|------------|------------|
| 资质 | `aptitude` | 闭关月修为 ×（资质÷10） | 白皮书第四节 / `cultivationFormula.service.ts` |
| 悟性 | `comprehension` | 炼丹、灵植成功率主属性 | 本册 4.3 |
| 神识 | `divine_sense` | **攻**；炼器、阵法主属性 | 交手 [combat.md](./combat.md) 4.4；百艺本册 4.3 |
| 遁速 | `speed` | **速**（只改承伤相对倍率） | [combat.md](./combat.md) 4.4 |
| 道心 | `dao_heart` | **防**；闭关心境；大境成功率与压陨落 | 交手 combat 4.4；闭关白皮书第四节；雷劫 [realms.md](./realms.md) 6.1～6.2 |
| 仙缘 | `fortune` | 历练是否出奇遇；宣称奇迹是否「气运微澜」 | 本册第 5 节 |

**明确不进的：**

- 资质 / 悟性 / 仙缘：**不进**普攻底数。
- 仙缘：**不改**天罚、越境扣血、境界秒杀。
- 遁速：**不**走路程（S31 未做）。旧函数 `getSpeedDodgeMultiplier`（相对固定基准 10）**不再**走交手主路径；现码用相对敌速。

灵根品质系数**只认**白皮书第四节。创角按灵根**数量**写品质（本册唯一）：1 天、2 地、3 真、≥4 **伪**。表里的「杂灵根」系数现码创角路径用不到，除非日后改品质判定。

## 4. 各系统怎么读六维

### 4.1 交手

映射：攻=`divine_sense`，防=`dao_heart`，速=`speed`。敌方三维按大境，见 combat 成册。压制与五行仍先于三维。

### 4.2 闭关

闭关乘式**只认** [game_design.md](./game_design.md) 第四节，本册不抄展开。日常闲逛的修为小增量仍可能走模型 `cultivation_delta`；**闭关**走该式。再乘逆天改命与创角命格的修炼乘数（相乘）。

### 4.3 百艺

命中技艺词 + 产物名才结算。成功率（0～1）：

```
rate = clamp(基础率 + max(0, 主属性) × 0.02, 0.05, 0.95)
成功 = rollFn() <= rate
```

主属性：炼丹/灵植 = 悟性；炼器/阵法 = 神识。注意：现码是 **整段属性 ×0.02**，不是「相对 10 的差」。悟性 10 的聚气丹基础 0.70 → 0.90。配方基础率见内容目录第 2 节。

### 4.4 雷劫

只读道心（加大境基础率、减失败陨落率）。功德另加成功率封顶。业力不改本骰。式子不在本册复制。

### 4.5 命格运行时

创角时：六维加减、气血/寿元/灵石一次性写入。

每回合行动：`getBuildCombat*` / `getBuildCultivationSpeedMultiplier` 再乘战斗与闭关（旧档同样生效）。未知出身/体质/道途/天赋名 **忽略**，不 500。

逆天改命（大境三选一）是另一套乘数，叠在命格之上，规格 **I26**。

## 5. 仙缘、机缘、运气（唯一语义）

仙缘是「多一次碰上非常之事的机会」，不是善恶权重，也不是战斗力。

### 5.1 出门历练奇遇

仅当意图是历练，且上一场未收束（`pending_scene === 'none'`）才掷。

```
chance = clamp(10 + max(0, 仙缘 − 10) × 1.5 + 地区加成, 0, 80)
triggered = (1d100 <= chance)
```

- 仙缘 **≤10**：都是基础 **10%**（再加地区）。气运差 **不会**低于中位、**不会**因此更常遇祸。
- 命中后第二次骰：**50% 重伤大能 / 50% 秘境**。与仙缘无关。文案允许传承或杀身之祸，好坏走后续叙事与交手，没有「霉运表」。
- **现码缺口：** `ActionService` 调用 `rollExplorationEncounter(fortune)` **未传入**地区 `fortuneEncounterBonus`。内容表里的地区加成目前只存在于 `EXPLORATION_REGIONS`，历练骰还没用上。加深探索（**I25**）时应接线并同步本小节。

越境扣血看境界位阶 vs 地区安全门槛，**不看仙缘**。

### 5.2 宣称奇迹骰

仅当句子命中封闭表（秒杀对方 / 神兵神器 / 反杀等），见 [plausibility.md](./plausibility.md) 第 3 节（**何时掷**以那份为准）。

```
chancePercent = clamp(3 + (仙缘 − 10) × 1.2, 1, 25)
triggered = (1d100 <= chancePercent)
```

仙缘 10 → 3%；1 → 仍有 **1%**；15 → 9%；封顶 25%。A5：成败只锁叙事，**不发物品、不改伤害**。差两境秒杀仍死。

### 5.3 故意不做

| 想法 | 现状 |
|------|------|
| 仙缘低 → 更高权重天灾、劫道、走火 | 无此骰 |
| 奇遇命中后按仙缘决定福祸 | 无；50/50 类型 + 叙事 |
| 业力天罚用仙缘减免 | 无；看功德业力（**I23**） |

## 6. 创角与开场

### 6.1 流程

1. 校验姓名等（网关）。
2. 抽轮回池候选；可能属性加成或埋藏物（**I27**）。
3. 聚合命格 → 六维夹 1～20、气血/寿元/灵石。
4. 写 `saves` / `world_state` / `players`；`talents` JSON 存出身、道途、体质、先天天赋。
5. `buildOpeningNarrative` 拼开场段与起步选项。

起始：年龄 16，气血/灵力上限基数 100（再加命格），无洞府。

灵根元素来自创角勾选；品质按数量（见第 3 节）。

### 6.2 选项必须对齐

前端数组 `origins` / `pursuits` / `constitutions` / `talentList` 必须与 `ORIGINS` / `DAO_PURSUITS` / `CONSTITUTIONS` / `INNATE_TALENTS` 的键、以及 `opening.service.ts` 模板键一致。改名：代码常量 + 创角页数组 + 开场模板 + 内容目录第 4 节。

效果数字**以 `characterBuild.service.ts` 为准**，内容目录是对照表。创角页旁注不是第三份规格，改乘数须先改代码再改内容表与页面文案。

开场段落是模板拼接，不是模型写的。命格铁律仍要求每回合叙事不写反身世。性别代词：男「他」、女「她」、其余「其」（`getGenderPronoun`）。

### 6.3 命格聚合

乘数（修炼、伤害、承伤）**相乘**；六维/气血/寿元/灵石 **相加**。然后创角夹六维 1～20。

## 9. 验收

- 创角页十出身、六道途、八体质、六先天天赋与后端键一致。
- 同境交手：神识高则打出更高（combat 单测）。
- 仙缘 1 与 10：历练触发率同为 10%（无地区加成时）。
- 仙缘 1：奇迹骰仍 ≥1%。
- 闭关：资质 20 约为资质 10 的两倍（其它系数相同）。
- 未知出身字符串：不 throw，当无加成。

手测：创角选书香门第，面板悟性应高于滑条；开场须写书香身世。
