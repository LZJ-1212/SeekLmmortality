# S25 多结局与成仙图鉴（规格）

规格先行。排期见 [roadmap.md](./roadmap.md) 阶段 E。现有：死亡锁、轮回池遗泽、大乘圆满数值指向「渡劫期·飞升」但 **无结局演出**。本系统把终局做成可复盘的标签与二周目资源。

---

## 1. 要解决的问题

死了像接口 403；飞升没有独立段落；没有「魔尊/功德圣人」等道途结算。成就点无法在无账号前提下跨周目，需要明确存储位置。

---

## 2. 实体

| 实体 | 一句话 |
|------|--------|
| 结局标签 | 一次终结的类型（死亡原因细化 + 飞升/魔途等） |
| 结局演出 | 固定段落 + 可选 AI 润色（润色失败则只用固定文） |
| 图鉴条目 | 玩家见过的结局/奇遇/灵兽等（第一期只做成结局） |
| 天道点 | 二周目用来解锁更高先天或加轮回池权重的点数 |
| 本机总账 | 无账号时的跨存档进度（见第 5 节） |

---

## 3. 结局触发（后端判定，AI 不投票）

| 标签（暂定 id） | 条件 |
|-----------------|------|
| `death_hp` | 气血 ≤ 0 且非坐化 |
| `death_lifespan` | 年龄 > 寿元 |
| `death_tribulation` | 雷劫失败且命中死亡掷骰 |
| `death_karma` | 天罚致命档 |
| `death_region` | 越境致死 |
| `ascend` | 大乘圆满雷劫成功且境界已是 `渡劫期·飞升`（键见 [realms.md](./realms.md)；演出仍未做） |
| `demon_lord` | 业力高于阈值 **且** 大境≥某档（阈值实现时写死并单测） |
| `sage` | 功德高于阈值且飞升或善终 |
| `lonely_immortal` | 飞升但人际关系全空 |
| `dao_companion` | 飞升或善终且存在双修对象未死 |

同一瞬间只选 **一个主标签**（优先飞升/魔尊，再死亡细分）。次要标签可并列进图鉴。

善终：寿元将尽时玩家选择「坐化闭关」类行动且未战死——第一期可只做死亡与飞升，善终作第二期。

---

## 4. 演出

- 后端设 `is_game_over` 同时写入 `ending_id`。
- 前端展示结局标题 + 段落；禁止 emoji。
- 允许一次 LLM 写「盖棺定论」但必须 `forcedOutcome` 已含标签与关键事实；失败则静态文案。

---

## 5. 天道点与无账号

L1 无登录。暂定：

- 表 `heaven_ledger`：**单机单库一行**（`id = 1`）累计天道点与已解锁图鉴 JSON。
- 多人共用同一 MySQL 会串进度——L1 可接受（朋友少）；L2 再按账号拆。
- 获得：首次达成某结局 +N 点；重复同结局 +0 或 +1（暂定重复 +1，封顶每结局 3 点）。
- 花费：轮回创角时解锁更高体质/天赋（须改创角校验，未解锁不能选）。

---

## 6. 铁律

- 结局不能由玩家输入「我飞升了」触发。
- 天道点不能改当前已死存档的数值，只影响下一世创角。
- 快照回滚：已写入的图鉴/天道点是否回滚？**暂定不回滚总账**（避免刷点）；当前存档结局标记随快照回滚。

---

## 7. 验收

- 每种死亡主标签至少一条单测。
- 飞升仅在雷劫成功链路上。
- 图鉴 JSON 非法时不崩创角。
