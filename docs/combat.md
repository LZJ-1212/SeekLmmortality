## 1. 要解决的问题

弱肉强食必须进公式：低一大境打不痛，低两大境必须能死。五行只左右可战局的细节，不能救人。模型可以写刀光剑影，不能把炼气写成反杀金丹。

玩家会试：一句话秒杀长老、战中捡神器、未习法术、乱报「太上境」。天道只认玩家真实 `realm_major`、表内位阶、以及拦截器算出的倍率。

## 3. 实体与字段

标识符与代码一致。

**位阶（只比大境，不比小境、不比修为）**

| `realm_major` | `REALM_RANKS` |
|---------------|---------------|
| 炼气 | 0 |
| 筑基 | 1 |
| 金丹 | 2 |
| 元婴 | 3 |
| 化神 | 4 |
| 炼虚 | 5 |
| 合体 | 6 |
| 大乘 | 7 |
| 渡劫期 | 8 |

`realmGap` = 玩家位阶 − 敌方位阶。正数表示玩家更高。

未知大境名（不在表内）：该侧视为与**对方已解析位阶**相同；双方都未知则双方 0。结果是 `realmGap === 0`，走可战局，不秒杀。轮回资格对未知大境当 0（**I27**），与战斗「跟对方齐」不同，禁止合成一套默认。

**玩家参战**

| 来源 | 用途 |
|------|------|
| `players.realm_major` | 位阶 |
| `players.spiritual_roots` JSON `elements` | 己方五行数组 |
| 逆天改命 `combatDamageMultiplier` / `combatDefenseMultiplier` | **I26**，可战局叠乘 |
| 命格 `getBuildCombat*` | **I28** |
| `players.divine_sense` | **攻**（与面板同一数字，夹 1～15） |
| `players.dao_heart` | **防** |
| `players.speed` | **速**；相对敌速只乘在**承受**伤上 |

**敌方（本回合 AI JSON，不落独立战斗表）**

| JSON 字段 | 用途 |
|-----------|------|
| `in_combat` | 无本场遭遇时，为真才开战；续场即使模型填 false 仍结算 |
| `enemy_realm_major` | 敌方位阶；缺省 `''` → 未知规则 |
| `enemy_element` | **单个**字符串；缺省则敌方空五行（中立） |
| `base_damage_to_player` / `base_damage_to_enemy` | **忽略**（兼容旧 JSON，不参与结算） |
| `enemy_name` | 开战写入本场遭遇；续场以库为准，模型改名无效 |

**本场遭遇（`world_state`，只活在 `scene_context=combat`）**

| 列 | 用途 |
|----|------|
| `encounter_hp` / `encounter_max_hp` | 本场气血；满值按敌大境位阶 `80 + 位阶×40`（炼气 80 … 渡劫期 400） |
| `encounter_name` / `encounter_realm` / `encounter_element` | 续场锁定身份，禁止模型中途换成大乘 |

击毙：`encounter_hp` 扣至 0，或差 ≥2 境玩家碾压。模型写「已死」而气血未绝 → **仍交手**。明确逃走（逃走/逃跑/撤退等）可脱身清遭遇，差两境秒杀仍不能靠跑活。

敌势档：未伤 / 轻创 / 带伤 / 残 / 绝（给日志，不做血条页）。

**结算结果 `CombatResolution` / `CombatTurnKind`**

| 字段 | 含义 |
|------|------|
| `outcome` | `player_instant_win` / `enemy_instant_win` / `normal` |
| `playerDamageMultiplier` | 已含境界 × 己方打敌的五行 |
| `enemyDamageMultiplier` | 已含境界 × 敌打己的五行（玩家承伤侧） |
| `narrativeHint` | 拼进日志 / 约束叙事 |

## 4. 规则与阈值（与代码同一套数字）

改倍率必须同步 `combat.service.ts` 常量与本表。

### 4.1 秒杀（先判，不再算五行）

`INSTANT_KILL_REALM_GAP = 2`（含）。

| `realmGap` | `outcome` | 玩家输出倍率 | 敌对玩家倍率 | 编排落血 |
|------------|-----------|--------------|--------------|----------|
| ≤ −2 | `enemy_instant_win` | 0 | 1 | 当前气血扣光（`hp → 0`），死因 `realm_suppression` |
| ≥ +2 | `player_instant_win` | 1 | 0 | 玩家不掉血；本场遭遇清零，对手气绝 |

秒杀文案须写明气运与法宝宣称不能改写。A5 成功只锁叙事，**不**改本表。

### 4.2 可战局境界倍率

| `realmGap` | 玩家打出 | 玩家承受（敌打出） |
|------------|----------|-------------------|
| −1 | 0.4 | 1.0 |
| 0 | 1.0 | 1.0 |
| +1 | 1.5 | 0.5 |

白皮书「高出一大境减伤 60%、玩家输出 40%」= 本表 `realmGap === -1` 的 0.4，不是另套公式。

### 4.3 五行（仅 `outcome === 'normal'`）

元素只认 `金木水火土`。其它字符串（含空、无属性）→ 该对组合倍率 1。

相克：木克土、土克水、水克火、火克金、金克木。

- 我克对方：× **1.3**
- 我被克：× **0.7**
- 我生对方：× **0.9**
- 对方生我（借力）：× **1.1**
- 同元素：× **1**

多对多：所有攻击元素 × 所有防御元素，取对**攻击方**最大的那个倍率。空数组当中立（实现用 `['']` 与空防御组合，结果为 1）。

最终：

```
playerDamageMultiplier = round(境界打出 × 己方打敌五行)
enemyDamageMultiplier  = round(境界承受 × 敌打己五行)
```

`round` 为四位小数（×10000 再除）。

### 4.4 交手三维与编排叠乘（可战局）

玩家三维与面板同一数字：攻=`divine_sense`，防=`dao_heart`，速=`speed`，夹 **[1, 15]**。

敌方三维按大境：`8 + 位阶×2`（炼气 8 … 金丹 12），三项同值，夹到 15。

对等底数：`10 + 攻 − 防`，夹 **[1, 40]**。

相对遁速（只乘承伤）：`1 + (敌速 − 己速) × 0.02`，夹 **[0.7, 1.3]**。

```
玩家掉血 = -round(底数(敌攻,己防) × enemyDamageMultiplier × 天赋承伤 × 命格承伤 × 相对遁速)
打出伤   =  round(底数(己攻,敌防) × playerDamageMultiplier × 天赋输出 × 命格输出)
```

资质、悟性、仙缘不进普攻底数。境界压制仍先判秒杀，再叠可战局倍率。`getSpeedDodgeMultiplier` 不再走交手主路径。

打出伤扣本场 `encounter_hp`。扣尽 → 气绝、结束交手。未扣尽 → 下一情境仍为 `combat`，**不采信**模型「已死 / 已走」。

秒杀两枝：**不**乘天赋/命格/遁速。`player_instant_win` 打出伤记为剩余遭遇气血，玩家不掉血。

突破/天罚/越境探索伤另有拦截器；与战斗同时出现时，气血优先级以 `action.service.ts` 现码为准（突破 patch 优先于战斗掉血；探索危险亦可盖过战斗伤）。本册不把探索伤算进 `resolveCombatModifiers`。

### 4.5 交手旗

无本场遭遇时，须 `in_combat === true` 才开战。已有遭遇时，本回合一律结算（含闲话，仍可能挨打）。逃走词清遭遇。下一情境由拦截器写 `combat` / `none`，不采信模型旗。

## 5. AI 合同

`DeducedActionCombat` 字段见 `ai.ts`。提示词要求：

- 有厮杀必须填 `combat`；无战斗且天道未写交手未歇则 `null`。
- 敌境须为九大境之一；**后端只查 `REALM_RANKS`**。续场改境无效。
- 禁止自行套压制；打出/挨打底数由天道按攻防速结算，JSON 估伤字段即使填写也不采信。
- 击毙以本场气血为准，禁止只凭文笔结束交手。

## 6. 铁律

- 功法、灵兽、伪装、仙缘骰、神器宣称 **不能** 取消差 2 境秒杀、不能把 0.4 改回 1.0。
- 未习招式声称法术：拦截器落空，叙事不得让术成真（S20 接入名表前维持）。
- 禁止新建 `/api/combat`；禁止把压制公式抄进 `playerState.service.ts`。
- 改 `REALM_RANKS` 必须同步本册第 3 节、[realms.md](./realms.md) 位阶表、探索/轮回引用。

## 7. 不做

- 小境参与压制。
- 独立敌人表、战斗页、网游式血条（本场气血只进天道日志与 `combat.summary`）。
- 敌方灵力条。
- 战中破境改本回合位阶（突破与战斗同回时，压制仍用行动开始时的 `player.realm_major`）。
- 用模型判「这怪该不该金丹」、用模型判气绝。

## 9. 验收（现码）

`combat.service.test.ts`（无 LLM）：

- 炼气 vs 金丹 → `enemy_instant_win`，打出 0。
- 金丹 vs 炼气 → `player_instant_win`，承伤倍率 0。
- 炼气 vs 筑基 → `normal`，打出 ≈0.4，承伤 ≈1。
- 筑基 vs 炼气 → 打出 ≈1.5，承伤 ≈0.5。
- 同境无五行 → 双方 1。
- 同境木打土 → 玩家打出 >1。
- 未知境 vs 炼气 → `normal`，`realmGap === 0`。
- `REALM_RANKS` 九名严格递增。
- 灵根 JSON 坏串 → `[]`，不 throw。
- 模型报估伤 9999 → 仍按攻防底数，不破局。
- 空串 / 太上境 / 金丹期 → 同阶，不秒杀。
- 扣尽本场气血 → `enemy_slain`，续场锁身份，模型报大乘不能改秒杀。
- 同境「逃走」→ `fled`。

手测：指令交手，日志见【天道】敌势；砍死前再写「它已死」应仍在交手。
