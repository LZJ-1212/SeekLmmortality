# 完善顺序与真实感路线（权威排期）

规格先行。本文件回答「先做什么、后做什么」。各系统细节见对应 `docs/*.md`。完成度见 [project_status.md](./project_status.md)。

北极星不是「系统数量 99%」，而是：**一周目 40～80 年寿命里，玩家能说出自己的师门、仇人、丹毒、错过的秘境、以及坟里的父母。**

---

## 0. 五根柱子（用来判断要不要加系统）

| 柱子 | 已有 | 本路线要补 |
|------|------|------------|
| 天道不讲情 | 境界压制、雷劫、死亡锁 | 心魔、毒誓、禁术、结局演出 |
| 岁月不等人 | 闭关扣寿、NPC 老死 | 凡人亲眷、赶路耗时、秘境档期 |
| 因果有账本 | 功德业力、宗门声望 | 大事记、师徒仇、江湖名声 |
| 资源会卡死 | 灵石、配方、洞府灵气 | 功法系数、丹毒、灵脉争夺 |
| 社会有规矩 | 宗门职位、坊市价 | 城中律法、关隘、情报真假 |

**内容表**（地区、配方、功法名录、人物志）与系统并行填，见 [content_catalog.md](./content_catalog.md)。机制演示填不满九州。

## 1. 不要做的（写进规格以免以后冲动开工）

- 模拟九州每一个路人（具名 NPC 约 20～50 + 模板路人）
- 全自动炼丹小游戏、气/经脉物理引擎
- 多玩家实时战场、拍卖行 MMO
- 夺舍改存档身份（S27 明确一周目禁用）
- 每个系统先做一块大 UI；优先快捷指令 + 日志 + 天机簿只读

## 4. 阶段完成的主观验收

- **A：** 朋友用浏览器能玩；无口令打不进 action。  
- **B：** 换功法能感到闭关快慢不同；乱吞丹会残。  
- **C：** 闭关十年后坊市有新传闻；归乡可能奔丧。  
- **D：** 飞升/魔途/破誓有标题；城里杀人进不了坊市。  
- **E：** 有兽、有曲、有假情报坑人——锦上添花。
