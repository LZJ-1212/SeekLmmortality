## 4. 阶段完成的主观验收

- **A：** 朋友能玩、无令牌打不进公网 action；战中闭关被拒；捡神器反杀走骰子；救完人写「搜寻机缘」不得无故换狐（A6）。  
- **B：** 十二系统各有成册；宗门/坊市/探索/天赋不是「只有拦截器没有表」；成册与代码无双源。  
- **C：** 换功法能感到闭关快慢不同；乱吞丹会残。  
- **D：** 闭关十年后坊市有新传闻；归乡可能奔丧。  
- **E：** 飞升/魔途/破誓有标题；城里杀人进不了坊市。  
- **F：** 有兽、有曲、有假情报——锦上添花。
