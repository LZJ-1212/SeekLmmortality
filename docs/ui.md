# 电脑与手机 UI 设计

规格先行。本文件记录 **当前已落地的分栏、色板、断点**。不是「产品永远只有指令加日志」的决议。整体界面与信息架构待办 **I19**（[roadmap.md](./roadmap.md)）。

**不写玩法公式、不写接口。** 指令点下去做什么见 [command_ui.md](./command_ui.md)；组件与分发见 [command_ui_architecture.md](./command_ui_architecture.md)。

产品气质：**宣纸书房**，不是赛博终端、不是马卡龙、不是图标 App。

---

## 1. 电脑 / 手机分别是什么

都是 **同一套浏览器前端**（`frontend/`），不是两套 App。差别只有视口宽度带来的分栏。

| | 电脑（宽屏） | 手机（窄屏） |
|--|-------------|--------------|
| 典型宽度 | ≥ **1024px**（笔记本全屏、外接屏） | ≤ **767px**（竖屏约 360～430） |
| 局内主结构 | 左「人物+指令」右「日志+输入」 | 上日志、下输入、**底栏指令** |
| 状态 | **已落地**（`lg:` / 1024） | **I11 未落地**；当前 &lt;1024 仍是细竖条过渡 |
| 禁止 | 再叠一排已删除的桌面「快捷」色块 | 汉堡里藏指令；图标-only 无汉字；原生包 |

中间宽度 **768～1023**：不算第三套玩法。布局用细竖条指令 + 右侧日志（过渡态）。I11 只把 **&lt;768** 改成底栏，不要为平板横屏再发明一套。

以 **CSS 宽度** 为准，不以「是否全屏」「是否触摸」「User-Agent」为准。

---

## 2. 断点（拍死）

Tailwind：`md` = 768px，`lg` = 1024px。与代码 `MainGame` 的 `lg:flex` / `min-width: 1024px` 对齐。

| 视口 | 名称 | 局内指令 | 人物面板 | 实现 |
|------|------|----------|----------|------|
| ≥ 1024px | 书房（电脑） | 左栏下方两列网格 | 左栏上方常驻 `StatusCard` | **已做** |
| 768～1023px | 窄窗 | 左侧细竖条 `rail` | 顶栏精简条；点「面板」弹层 | **已做**（过渡） |
| &lt; 768px | 掌中（手机） | 底部 4 列 × 多行 | 顶栏精简条；点「面板」弹层 | **I11 未做** |

旧稿曾写「768 以上即桌面左栏」。作废。桌面书房只认 **1024**。

## 3. 视觉铁律（两套布局共用）

### 3.1 结构

- 游戏界面是宣纸大面板：`bg-paper` + 彩色边框（默认 `border-jade`），不要全屏无边碎块风。
- 一屏一个主任务：列表 / 创角 / 局内。不要多页签游戏大厅。

### 3.2 文案与装饰

- 剧情、系统日志、选项、AI 叙事 **禁止 emoji**。
- 音量按钮可用克制 SVG（见 [audio_system.md](./audio_system.md)）；未做声音前不要先摆一排假按钮。
- 对玩家短讯修仙口吻；不要把堆栈打在局内日志当正文。
- 指令必须有汉字。禁止汉堡菜单把指令藏起来。

### 3.3 选项

动态选项直接列在日志下方，带语义标签：`〔机缘〕` `〔风险〕` `〔平和〕` 等。标签配色用主题类（jade / mystic / blood），不要新开一套。

### 3.4 色板（摘要；完整以 `tailwind.config.js` 为准）

| 用途 | 类名思路 | hex（配置值） |
|------|----------|----------------|
| 大面板底 | `bg-paper` | `#FBF8F1` |
| 战斗/警告底 | `bg-dangerBg` | `#FBEDE9` |
| 机缘底 | `bg-mysticBg` | `#F5EFF9` |
| 进度条底 | `bg-progressBg` | `#E8E4DC` |
| 主边框/平和 | `border-jade` / `text-jade` | `#6FA698` |
| 雷劫/突破 | `thunder` | `#8B6FA8` |
| 气血/风险 | `blood` | `#C05F55` |
| 财富/分隔 | `gold` | `#C9A45C` |
| 灵力 | `water` | `#5E8FAE` |
| 修为 | `cultivation` | `#A87E2E` |
| 寿元 | `lifespan` | `#5C8C6E` |
| 正文 | `text-textMain` | `#3F3A34` |
| 次要 | `text-textSub` | `#8C8578` |

禁止新内联马卡龙色。情缘可用已有 `romance` / `romanceBg`。

### 3.5 字号

局内日志字号可调，约 12～24px，默认约 15px，存在本机（现键名 `sl_font_size`）。创角/列表用主题默认即可，不必第二套字号系统。

## 4. 电脑（书房）布局

目标：外接屏或笔记本拉宽后，左边是「人」，右边是「事」，指令够宽、能并排，不要 104px 细条。

```
┌──────── 约 420px ────────┬──────────── flex-1 ────────────┐
│  StatusCard（常驻、可滚）  │  顶栏：九州 · 字号 · 天玄历     │
│                          ├───────────────────────────────┤
│  指令 两列网格            │  日志（主阅读区，可滚）         │
│  14 键，汉字               │  动态选项                      │
│                          │  输入框 + 行动                 │
└──────────────────────────┴───────────────────────────────┘
```

规则：

- 左栏与状态卡同宽（约 420px），`CommandMenu variant="underPanel"`。
- 宽屏顶栏精简状态条可隐藏（数值已在左栏）。
- 点「面板」：面板已常驻，**不再盖一层**同样的状态卡。
- 背包 / 洞府 / 宗门 / 情缘、读档：仍弹层；弹层 `max-w` 限制，桌面不要拉满整屏。
- 处理中 / 死亡：行动类指令禁用；信息类与读档仍可开。

页面（电脑）：

| 页 | 设计 | 代码（约） |
|----|------|------------|
| 存档列表 | 居中宣纸卡，约 `max-w` 560；列表可滚；「新开仙途」；口令只在该页新开下方 | `SaveList.tsx` |
| 创角 | 居中卡，选项与内容表一致 | `CreateCharacter.tsx` |
| 局内 | 上图 | `MainGame.tsx` |

## 5. 手机（掌中）布局

目标：竖屏能看完日志、点得中指令、打字不被键盘挡住。不改后端。

I11 落地后局内：

```
┌─────────────────────────────┐
│ 顶栏 九州 · 字号 · 天玄历     │
│ 精简状态条（可换行）           │
├─────────────────────────────┤
│ 日志（占满剩余高度，可滚）     │
├─────────────────────────────┤
│ 动态选项（可换行）             │
│ 输入 + 行动                   │
│ 指令底栏 4 列 × n 行          │
│ 底部安全区（Home / 刘海）      │
└─────────────────────────────┘
```

规则：

- **禁止**左侧再留 104px 指令栏与日志抢宽。
- 根高度跟 **可见视口**（优先 `100dvh`；iOS 仍挡再 `visualViewport`）。输入行在键盘上方仍可见。
- 点击目标：指令格约 ≥ 44×36 CSS 像素；主按钮高度 ≥ 40px。无 hover 也要看得出可点。
- 弹窗：宽接近视口留边，高约 85% 可视区，内滚。`StatusCard` 不得死宽 `w-[420px]`。
- 存档 / 创角：单列全宽留边约 16px，`w-full max-w-lg`；长表单整页可滚到主按钮，不要垂直居中切掉底部。
- 不做：原生 App、PWA 安装页、暗色 OLED 主题、手势划页、微信小程序。

过渡态（I11 未做时）：手机打开也会落到「768～1023 细竖条」那套，日志偏窄——这是已知缺口，不是设计目标。

## 6. 组件与变体

同一套指令数据与 `handleCommand`，只换摆放：

| 变体 | 用于 | 状态 |
|------|------|------|
| `underPanel` | ≥1024 左栏下 | 已做 |
| `rail` | 768～1023；I11 前一切 &lt;1024 也走这条 | 已做 |
| `dock`（或 MainGame 底栏 map） | &lt;768 | **未做** |

禁止 `MobileMainGame.tsx` 复制一份局内逻辑。

---

## 7. 明确不要

- 为手机绕过口令、日限、死亡锁，或第二套 `fetch` 基址。
- 用 User-Agent 切换「手机站」。
- 第三套平板专用玩法布局。
- 新内联马卡龙色；剧情 emoji。
- 把「指令栏 + 日志 + 纯文字弹层」写成最终形态（那是现状，不是目标）。完整设计走 **I19**。

## 9. 验收（设计是否到位）

**电脑（≥1024）**

- 左栏出现完整状态卡，其下指令两列、明显宽于 104px。
- 点「面板」不重复盖状态卡；点「修炼」仍发 `闭关修炼`。

**窄窗（约 900px）**

- 细竖条 + 日志仍可用；无整页乱套。

**手机（I11 落地后，≤390px）**

- 见 [mobile.md](./mobile.md) 第 7 节（列表、创角、局内、键盘、指令）。

前端改布局后：`frontend` 下 `npm run build` 过。
