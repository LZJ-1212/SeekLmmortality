# 情境锁（不合理行动）

修订：2026-09-05 14:40 +08 lzj — 战斗公式指向成册 combat.md

规格先行。自由度总则见 [player_agency.md](./player_agency.md)（本文件是其中 **层 1 硬拒绝**）。实现落在 `situation.service.ts`，由 `/api/action` 在配额与闭关等拦截器**之前**调用。不改压制倍率；倍率见 [combat.md](./combat.md)。

---

## 1. 要解决的问题

玩家可以在交手当口输入「闭关修炼」。当前只要句子里有「闭关」，后端就会解析月数、加修为、让 AI 写「山中无甲子」。战斗没有跨回合状态，等于刀还没放下就能进洞府十年。这不是「AI 演得圆」，是数值作弊。

---

## 2. 范围

| 项 | L1 |
|----|-----|
| 上一回合若判定为交手，本回合禁止闭关、坊市、拍卖、炼器炼丹、双修 | **必做** |
| 拒绝时：400、修仙口吻短讯、**不调 DeepSeek**、不改气血/修为/时间、**不占日限** | **必做** |
| 情境写入 `world_state.scene_context`（快照回滚一并还原） | **必做** |
| 用大模型给每句话打「合不合理」分 | **L1 不做**（贵、不稳、可被绕） |
| 穷尽所有小说桥段（战中顿悟破境等） | **L1 不做**；战中**突破**暂仍允许（已有拦截器） |

---

## 3. 实体

| 实体 | 取值 |
|------|------|
| 情境 | `none`（默认） / `combat`（上一有效回合 AI 报了交手） |
| 意图 | `seclusion` / `shop` / `auction` / `craft` / `dual_cultivation` / `other` |

---

## 4. 规则

**写入情境（仅在本回合已成功推演之后）**

- `combat.in_combat === true` 且未死亡 → `combat`
- 否则 → `none`（含闭关结束、聊天、赶路）
- 本回合被情境锁拒绝 → **不改**情境

**`combat` 下禁止的意图**

- 闭关（含快捷「修炼」发出的「闭关修炼」）
- 坊市买卖、拍卖喊价
- 炼丹/炼器/阵法/灵植
- 双修

允许：继续交手、逃、求饶、吃药（若有物）、突破。

**拒绝文案（对玩家）**

- 闭关：刀剑未歇，岂能盘膝入定。
- 坊市：厮杀之间，坊市远在天边。
- 拍卖：拍卖席上并无你的席位。
- 百艺：烽火之中，丹炉如何安放。
- 双修：生死一线，岂能双修。

---

## 5. 铁律

- 禁止靠 prompt「请不要让玩家战中闭关」代替本锁；AI 仍会圆、拦截器仍会加修为。
- 禁止拒绝之后还跑闭关公式。
- 功法、灵兽以后也**不能**取消本锁。

---

## 6. 验收

- 情境 `combat` + 输入「闭关修炼」→ 400，修为不变，无 DeepSeek。
- 情境 `none` + 「闭关修炼」→ 仍走闭关拦截器。
- 单测覆盖允许/拒绝；骰子不依赖真实随机。

战中喊「捡神器反杀」**不会**走本文件的 400：那是另一类宣称，见 [plausibility.md](./plausibility.md)（封闭意图 + 仙缘骰，且破不了差两大境秒杀）。
