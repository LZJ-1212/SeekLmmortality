# S35 灵脉与洞府争夺（规格）

规格先行，代码未写。排期见 [roadmap.md](./roadmap.md) 阶段 C 末。洞府与灵气已有；本系统让「灵脉不是你的私产」。大势骰见 [world_sim.md](./world_sim.md)。

---

## 1. 要解决的问题

洞府须开辟或宗门赐府才有记录；创角不送府。无府仍可借地闭关（灵气打折）。灵脉被抢、坊市租赁见本系统实现时再接。

---

## 2. 实体

| 实体 | 一句话 |
|------|--------|
| 灵脉点 | 与地点绑定的灵气上限 |
| 洞府占用 | 玩家或 NPC/宗门标记 |
| 搬迁 | 耗时、暴露新坐标 |
| 征用事件 | 大势结果：被逐 / 纳贡 / 开战 |

---

## 3. 规则（暂定）

- 炼气期：只能在坊市租赁低灵气洞府，不能占山。  
- 筑基+：可占无主灵脉（内容表）。  
- S24 抽中「灵脉争夺」且玩家正在该点：三选一硬结果——纳贡灵石 / 放弃搬迁 / 开战（走战斗，敌人境界受控，禁止无提示差 2 境）。  
- 搬迁：赶路 + 1 月安顿；旧洞府灵气清零到默认。  

第一期不做波及伤害「天劫劈山误伤玩家」（与 world_sim 一致）。

---

## 4. 铁律

- 灵气系数仍只来自洞府数值，不由 AI 报。  
- 无主脉须在表内，不能口头占「昆仑」。

---

## 5. 验收

- 炼气不能占山。  
- 征用三分支都有单测。  
- 搬迁后地点与灵气一致。
