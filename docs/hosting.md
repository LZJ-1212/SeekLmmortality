## 1. 要解决的问题

本机 `5174` + `3000` 只有你自己能玩。前端 API 基址已抽到 `frontend/src/apiBase.ts`。**未设** `VITE_API_BASE` 时仍缺省本机 3000：朋友即使用穿透打开你的页面，请求仍打向**他们自己电脑**的 3000。关机或关掉终端 = 朋友立刻玩不了。把 3000 裸映射公网且无口令 = 别人烧你的 DeepSeek。

## 2. 范围（L1 必做 / 明确不做）

| 项 | L1 |
|----|-----|
| 朋友用浏览器打开一个（或两个）HTTPS/HTTP URL 即可玩 | **必做** |
| 配置 `PLAY_ACCESS_TOKEN` 后再暴露任何公网入口 | **必做** |
| 前端请求打到**你的**后端，而不是朋友机器上的 localhost | **必做** |
| MySQL、XAMPP、`.env`、DeepSeek Key 只留在服主机 | **必做** |
| 后端 + 前端 + MySQL 在你关机/关终端后仍能被拉起或明确告知「服主不在线」 | **必做**（保活或诚实停服） |
| 改代码不影响正在玩的朋友（另目录 / 另端口 / 实验库） | **必做**（步骤见 [runbook.md](./runbook.md) 第 7 节） |
| 买云主机、备案、CDN、Docker、CI 部署 | **L1 不做**（可作备选拓扑，见架构文） |
| 账号系统、HTTPS 证书自签以外的商业证书 | **L1 不做**（隧道产品自带 HTTPS 即可） |
| GitHub Pages 托管本游戏 | **禁止**（无 Express/MySQL） |

## 3. 实体

| 实体 | 一句话 |
|------|--------|
| 服主机 | 跑 MySQL、后端、前端的那台 Windows（通常是你的电脑） |
| 前端 Origin | 朋友地址栏里的创角/局内页来源（含协议+主机+端口） |
| API Origin | 朋友浏览器发出 `/api/*` 的目标来源 |
| 隧道/反代 | 把公网 URL 转到服主机本地端口的一层（穿透或 Nginx） |
| 游玩口令 | 与 I04 同一 `PLAY_ACCESS_TOKEN`；可逗号多条。朋友在**存档列表**页填写自己那一条（创角页不再填） |
| 保活单元 | 崩溃或开机后自动拉起的进程（MySQL、后端、前端） |
| 朋友须知 | 你口头或私聊发给朋友的短说明（URL、令牌、勿外传） |

## 4. 规则与阈值

**暴露面**

- 公网最多暴露：前端 Origin、API Origin（若与前端不同源）。
- **禁止**暴露 `3306`、phpMyAdmin、XAMPP。
- **禁止**只映射 `3000` 且无口令。
- 未配置 `PLAY_ACCESS_TOKEN`：**禁止**做端口映射或开隧道。

**CORS 与口令**

- 前端 Origin 与 API Origin 不同源时：后端 `PLAY_CORS_ORIGIN` 必须等于前端 Origin（精确匹配，不要 `*`）。可逗号分隔多个。**本机 `http://localhost:5174` / `http://127.0.0.1:5174` 始终放行**（历史 `5173` 一并放行），以免配了公网 CORS 后本机创角失败。
- 同源反代时：CORS 可收紧为该公网 Origin；接口走相对路径 `/api`。
- 朋友请求（穿透）必须带 `X-Play-Token`（存档页令牌栏；见 S21）。本机直连可不带。

**可用性**

- 服主机休眠、关机、断网 → 朋友无法玩；须在朋友须知里写明。
- 进程崩溃后 L1 要求：**能自动重启后端**（前端与 MySQL 同级更好）；做不到则文档写「需服主手动 `npm run dev`」。
- 不要求 99.9% SLA。

**成本**

- 叙事仍走你的 DeepSeek Key；靠 I04 日限 + 口令挡刷，不靠 I06 再做一层计费。
- 隧道选免费档即可；付费穿透不是门槛。

## 7. 验收（L1）

- 另一台设备（或朋友）不装 Node/MySQL，只开浏览器，能创角并走出第一步行动。
- 浏览器网络面板里 `/api/action` 的 Host 不是朋友自己的 `localhost`。
- 无令牌的**穿透**请求受保护接口 → 401；有令牌才能玩。本机直连即使配了口令也可以不带令牌。
- 关掉服主机上的后端进程 → 朋友侧失败且不泄漏 Key。
- 单测：不测真实隧道厂商；I06 若改前端 API 基址，前端 `build` 必须过。
