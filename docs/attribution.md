# 文件修订署名

修订：2026-09-02 21:37 +08 lzj — 新建多人协作署名与时间底线

排期外的协作底线。Cursor 强制执行见 `.cursor/rules/attribution.mdc`。双人流程见 [dev_guide.md](./dev_guide.md)。

**Git 的 author / date 不能代替本文件要求的文件内修订行。** 两人看同一份 md/ts 时要立刻知道谁、何时动过。

---

## 1. 什么时候签

| 动作 | 要签吗 |
|------|--------|
| 新建 `docs/*.md`、`.ts`、`.tsx`、`.mdc` | **要**（写「创建」） |
| 改已有代码或文档（含只改一句） | **要**（追加一行） |
| 同一回合对同一文件多次保存 | 只留 **一行** |
| `node_modules`、生成代码、`.env`、锁文件 | **不要** |

---

## 2. 署名与时间

| 署名 | 谁 |
|------|-----|
| `lzj` | 仓库主人；工作分支 `lzj` |
| `Loading_line` | 朋友；工作分支 `Loading_line` |

时间：**北京时间**，格式 `YYYY-MM-DD HH:mm +08`。Agent 用当前会话时间戳，不要写「刚才」。

---

## 3. 文档怎么写

新建或第一次补署名：标题下第一段（或紧跟标题）写一行：

```
修订：2026-09-02 21:37 +08 lzj — 成册境界雷劫
```

已有多条时改成表，**新行加在表顶**（最近的在上）：

```
| 时间 | 作者 | 说明 |
|------|------|------|
| 2026-09-03 10:12 +08 | Loading_line | 补验收句 |
| 2026-09-02 21:37 +08 | lzj | 成册境界雷劫 |
```

表最多 **8** 行；挤掉最旧的。说明写人能看懂的一句，禁止只写「更新」。

---

## 4. 代码怎么写

文件最顶（`import` 之前）一块注释。新建：

```typescript
/** 修订：2026-09-02 21:37 +08 lzj — 新建 playerState 日段钟 */
```

追加：

```typescript
/**
 * 修订：
 * 2026-09-03 10:12 +08 Loading_line — 终局键 isTerminal
 * 2026-09-02 21:37 +08 lzj — 新建 playerState 日段钟
 */
```

只签 **文件**，不要在每个函数上再签。测试文件与实现文件各签各的（改了哪份签哪份）。

前端 `.tsx` 同样：`'use client'` 若有则在其后、`import` 前。

---

## 5. 禁止

- 用模型猜作者；以当前分支为准（`lzj` / `Loading_line`）。
- 为了署名去改无关文件或回填全仓库历史。
- 把密钥、本机路径写进修订说明。
