# I11 手机浏览器适配（功能规格）

规格先行。电脑/手机长什么样见 [ui.md](./ui.md)（断点：书房 1024、掌中 768）。布局开工顺序见 [mobile_architecture.md](./mobile_architecture.md)。本机 / 朋友穿透仍以 [runbook.md](./runbook.md)、[hosting.md](./hosting.md) 为准。

**不改玩法、不改后端接口。** 手机走同一套 `/api/*`、同一口令与日限。解决的是：竖屏能看完、点得中、打字不被键盘挡住。

---

## 1. 要解决的问题

当前前端按桌面排：≥1024 已是左栏书房；**&lt;1024** 仍是细竖条约 104px + 日志。创角 / 存档 / 弹窗仍有固定像素宽。手机浏览器能打开隧道 URL，但日志过窄、卡片易溢出、输入被键盘挡住、指令偏小。L1 朋友大量用手机，不适配等于「能连不能玩」。

---

## 2. 范围（L1 必做 / 明确不做）

| 项 | L1 |
|----|-----|
| 竖屏（约 360～430 CSS 宽）能完成：存档列表（含口令）→ 创角 → 局内一条行动 → 打开面板/背包类弹窗 | **必做** |
| 窄屏局内：日志全宽；指令改到底栏（可换行），不再与日志抢横向空间 | **必做** |
| 创角 / 存档列表 / 信息弹窗 / 读档弹窗：宽度随屏，`max-w` 限制桌面，禁止固定像素把小屏撑出横向滚动 | **必做** |
| 局内输入区：弹出键盘时日志仍可滚、输入框仍可见（不为键盘盖死） | **必做** |
| 点击目标：指令与主按钮高度足够手指点（见架构文阈值） | **必做** |
| 主题色、无剧情 emoji、口令/日限/死亡锁 | **不变** |
| 原生 App、应用商店、强制 PWA 安装页、独立手机域名 | **L1 不做** |
| 新后端接口、为手机单独一套 action 语义 | **禁止** |
| 平板横屏「第三套布局」 | **L1 不做**（768～1023 用细竖条；≥1024 用书房。见 [ui.md](./ui.md)） |
| 鼠标 hover 在触摸上的等效（长按菜单等） | **L1 不做**；按钮须在无 hover 时也看得出可点 |

---

## 3. 实体

| 实体 | 一句话 |
|------|--------|
| 窄屏 | 视口宽度 **小于** 断点（默认 768px，见架构文）时的布局 |
| 宽屏 | ≥1024：书房（左栏面板+指令）；768～1023：细竖条。见 [ui.md](./ui.md) |
| 指令底栏 | 窄屏下指令的唯一入口；与 [command_ui.md](./command_ui.md) 同一套名字 |
| 安全区 | 刘海 / Home 条：底栏与输入不被系统手势条挡住 |
| 可视视口 | 含虚拟键盘后的可见高度；输入区贴这块区域的底，而不是整页 `100vh` 被键盘顶飞 |

---

## 4. 规则与阈值

**断点（与 [ui.md](./ui.md) 对齐；作废「768 以上即桌面书房」）**

- **&lt; 768px**：掌中；指令底栏。本文件 L1 必做。
- **768～1023px**：窄窗细竖条，不算第三套玩法。
- **≥ 1024px**：书房；左栏常驻面板 + 指令在下，见 [command_ui.md](./command_ui.md)。

禁止再为「手机 / 小平板 / 桌面」分叉玩法。

**三页布局**

- **存档列表、创角**：单列、全宽留边距（约 16px），面板 `w-full max-w-lg`（或等价），高度随内容滚动，不要 `items-center` 把长表单卡在屏中间切掉底部按钮。
- **局内窄屏**：纵向：顶栏（九州 + 字号 + 天玄历）→ 精简状态条（可换行）→ 日志（占满剩余高度，可滚）→ 动态选项（可换行）→ 输入行 → **指令底栏**。禁止左侧再留 104px 指令栏。
- **局内宽屏（≥1024px）**：左栏常驻人物面板，指令在面板下方两列，见 [command_ui.md](./command_ui.md)。不是细竖条。

**指令（14 个，名字与顺序不变）**

`面板・修炼・突破・悟道・洞府・地图・背包・坊市・宗门・技艺・情缘・对话・存档・读档`

- 点击语义与现桌面一致：信息类弹窗、行动类发同一套标准文本、存档回列表、读档开快照列表。见现 `MainGame` / `CommandMenu`。
- 窄屏底栏允许 **4 列 × 多行** 或横向可滑 + 换行，以「不挡日志、一屏能看到全部指令」为准；不得改成汉堡里藏指令导致找不到「修炼」。
- 处理中 / 已死亡：行动类禁用规则与现桌面相同；面板 / 背包 / 洞府 / 宗门 / 情缘仍可开；读档仍可开。

**弹窗**

- 窄屏：`w` 接近视口（留边），`max-h` 约 85% 可视高度，内容区滚动；点遮罩关闭行为保持。
- 「面板」弹窗里的 `StatusCard` 不得再强制 `w-[420px]`。

**键盘与视口**

- `index.html` 保持 `viewport`；L1 可加 `viewport-fit=cover` 以便安全区，**不要** `user-scalable=no`（无障碍）。
- 局内根容器高度跟 **可见视口**（键盘弹起后变矮），输入行贴在日志下方、键盘上方，禁止整页被顶到只剩半截标题。
- 不要求 iOS/Android 像素级一致，验收以「能看见输入框并提交一条行动」为准。

**文案**

- 对玩家短讯仍用修仙口吻；不因窄屏改接口错误码。

---

## 5. 铁律

- I11 **不得**为手机绕过 `X-Play-Token`、日限、死亡锁、注入黑名单。
- I11 **不得**新增第二套 `fetch` 基址；仍走 `apiFetch` / `VITE_API_BASE`。
- I11 **不得**新开马卡龙色或剧情 emoji。
- I11 **不得**把指令改成图标-only 且无汉字（窄屏仍须能读「修炼」「突破」）。

---

## 6. 与其它系统

- 依赖已落地：局内指令菜单、存档列表、读档弹窗、I06 API 基址。
- 不依赖原生推送、PWA 离线包。
- 不替代 [geography.md](./geography.md) 的「地图」玩法；窄屏「地图」仍发现有行动文本。
- [game_design.md](./game_design.md)「指令行常驻」：宽屏在左栏，窄屏在底栏，**不是**再做一排桌面底栏快捷（那一排已删）。

---

## 7. 验收（L1）

真机或浏览器设备模式，宽度 ≤ 390px：

1. 存档列表可滚、可删、可「新开仙途」，无横向整页滚动。
2. 存档页口令栏点得中；创角表单可滚到「踏入仙途」，选项点得中。
3. 局内日志可读；全部指令可点；点「面板」「背包」弹窗不溢出屏外。
4. 点输入框弹出键盘后，能看见输入框并提交一条行动（日志可滚）。
5. 宽屏（≥1024）打开同一页：左栏面板 + 其下指令，见 [command_ui.md](./command_ui.md)。
6. `frontend` 下 `npm run build` 过。无新后端单测要求（无新公式）。

---

## 8. 明确不做（本规格）

- 微信小程序 / 独立 Android 包
- 手势划动切「面板页」（避免误触发行动）
- 为触摸重做战斗 QTE
- 暗色 OLED 专属主题
