# 宣称奇迹与不合理行动（分层，不是一个「AI 判不合理」）

规格先行。**自由度总则**（玩家能说什么、天道锁什么、何时配新代码）见 [player_agency.md](./player_agency.md)。情境硬锁见 [situation.md](./situation.md)。战斗铁律见 `combat.service.ts`（差两大境秒杀，功法/仙缘/**捡神器都不能取消**）。本文件回答两件事：

1. 「战中捡绝世武器反杀」这种**有可能、但看气运**的句子，**什么时候**才跑掷骰代码。  
2. 其它乱七八糟的输入，**不靠一个万能分类器**，靠分层。

**L1 代码：** 情境锁已做；本文件的仙缘奇迹骰 **已接线**（`miracle.service.ts`，路线图 **A5 / S36**）。A5 成功只锁叙事、不发物品、不改伤害；凡器掉落、承伤×0.7、脱身属完整档，后做。禁止先让模型演神兵。

**L1 与完整档：** 第 3.1 词表、第 3.3 概率、第 7 节验收是 **A5 必做**。第 3.2 里「发凡器 / 承伤×0.7 / 脱身」是 **完整档**，A5 **不做**——成功只锁叙事。调用顺序以 [player_agency.md](./player_agency.md) 第 7 节为准（日限与既有拦截器之后、`deduceAction` 之前）。

## 1. 不要做什么

| 做法 | 为什么不行 |
|------|------------|
| 让 DeepSeek 判断「这句话合不合理」 | 模型会顺着玩家演；还会编神器。贵。 |
| 一个「不合理」黑名单想穷尽所有句子 | 换个说法就绕过。 |
| 仙缘骰成功 → 秒杀高两境的敌人 | 违反境界压制铁律。气运不是龙傲天开关。 |
| 成功就往背包塞任意「绝世神兵」 | 物品必须在图鉴或本局自定义条目里，见 AI 物品铁律。 |

已经有、能挡一部分的：

- 注入句（改数值/套密钥）→ 黑名单，不调模型。  
- 战中闭关/坊市/炼丹/双修 → 情境锁 400。  
- 声称使用图鉴里有、背包里没有的道具 → `detectFabricatedItemUsage`。  
- AI 报的战斗伤害/胜负 → `resolveCombatModifiers` 重算；差 ≥2 大境仍秒杀。

挡不住的：玩家打「我捡到绝世武器反杀了他」——句子里没有图鉴物名，闭关拦截器也不触发，模型很容易写成你赢了。这要靠下面第 3 层「宣称奇迹」。

## 2. 三层（由硬到软）

```
玩家输入
  │
  ├─ 层 1 硬拒绝     与当前情境物理上不能同时成立（战中闭关）
  │                  → 400，不调 AI，不掷骰
  │
  ├─ 层 2 铁律覆盖   境界差、死亡锁、物品熔断（日限是配额，不是本层）
  │                  → 可调 AI，但 forcedOutcome 锁死；骰子改不了秒杀
  │
  └─ 层 3 宣称奇迹   玩家用语言「宣布」一件本不该由他决定的好运
                     → 仅当命中封闭意图表 才掷仙缘骰
                     → 成功/失败都写进 forcedOutcome，AI 只准描写
```

层 3 **默认不跑**。大多数话（砍一刀、求饶、逃跑、喝酒壮胆）走 `other`，不掷骰，交给战斗公式 + 模型叙事。

## 3. 「仙缘奇迹骰」何时触发（拍死）

必须**同时**满足：

1. `detectMiracleClaim(action)` 命中下表**封闭意图**（子串，和闭关检测一样，可单测，禁止上模型分类）。**不要求**上一回合已是 `combat`（第一刀就喊反杀也要检）。  
2. 本句不是层 1 已拒绝的意图（战中闭关等仍走情境锁 400，不进本骰）。

境界差**不是**「要不要跑这段代码」的条件。未命中表 → **不调用**本骰子函数。A5 无缓存敌境时，境界差也不改骰成败（见 3.2 L1）。完整档才用 3.2 表限制成功上限。

### 3.1 封闭意图表（L1 只做这几条）

匹配规则：**明文子串**；与闭关检测一样可单测。**禁止正则、禁止模型分类。**（词表全中文，无大小写问题。）  
`miracle_loot` 的兵器行写成多条短词，不要写成 `捡到.*剑`。

| 意图 id | 触发子串（实现时写死数组，命中任一条即可） | L1 骰成功 | 骰失败 |
|---------|-------------------------------------------|-----------|--------|
| `miracle_reversal` | 反杀、绝地逢生、以弱胜强、逆转战局 | 只锁叙事：气运微澜，胜负仍走战斗公式 | 妄念落空；叙事须写天不认，**L1 不改承伤数字** |
| `miracle_loot` | 绝世武器、神兵、神器、天降法宝、捡到剑、捡到刀、捡到枪 | 同左：不入库、不发凡器 | 摸到断刃/石头，无物 |
| `miracle_instant_kill` | 秒杀对方、一招毙命、直接打死他 | **禁止**当秒杀用。按 `miracle_reversal` 成功档叙事（仍不改公式） | 同失败 |

一句命中多条：优先级 `miracle_instant_kill` > `miracle_loot` > `miracle_reversal`（先处理最狂的宣称）。

`miracle_instant_kill` 在**完整档**里比 `miracle_reversal` 更苛：敌高 ≥1 境视为失败档；`miracle_reversal` 敌高 1 境仍可走减伤/脱身。这是故意的（喊得越狂罚得越重），不是笔误。**A5 两档成功都不改伤害**，此区别只影响完整档 3.2。

未命中表 → **不调用**本骰子函数。这就是「什么情况会触发这段代码」的唯一答案：`detectMiracleClaim` 非空。

### 3.2 成功了也不能破铁律

`realmGap` = 玩家大境序号 − 敌境序号（与 `combat.service.ts` 一致：负值表示敌更高）。

**A5 / L1（无敌境也必须能掷骰）**

- 掷骰只看仙缘与 3.3，**不把敌境当「要不要跑代码」的条件**（与 3.1 一致：第一刀喊反杀也要检）。  
- **本回合算骰时若没有缓存敌境**（交手锁尚未记下 `enemy_realm_major`）：成功/失败都只写 `forcedOutcome` 叙事句；**禁止**按猜测敌境发物品或改伤害。落地秒杀/减伤仍等本回合 AI 报 `combat` 之后的 `resolveCombatModifiers`。成功句须带「胜负仍以境界压制为准」；失败句「妄念落空」。  
- **已有缓存敌境** 且敌高 ≥2 境：无论骰成败，`forcedOutcome` 写明气运再好也难逃降维；伤害仍走 `enemy_instant_win`。  
- A5 **不发物品、不乘承伤、不提前结束交手**。秒杀提示词不得写「逆天法宝托底」（接线时改 `combat.service.ts` 里那句）。

**完整档（A5 之后，须先有敌境缓存）**

先算 `realmGap`。敌境来自交手锁缓存；禁止为了发物品再信本回合模型把金丹报成炼气。

| 境界差 | 仙缘骰成功的上限（完整档） |
|--------|----------------------------|
| 敌高 ≥2 境 | **骰子作废**，仍 `enemy_instant_win`。forcedOutcome 写明：气运再好也难逃降维。 |
| 敌高 1 境 | 最多：本回合承伤再乘 0.7，或允许「脱身」结束交手（情境改 `none`），**不许**把对方打死。`miracle_instant_kill` 此档视为失败。 |
| 同境或玩家更高 | 可给：图鉴凡器一件，或本回合对敌伤害 ×1.2；仍走 `normal` 伤害，不改成 `player_instant_win`（除非公式本身已是玩家碾压）。 |

仙缘只改**概率和上限档**，不改秒杀阈值。

### 3.3 概率公式（拟，与奇遇骰同风格）

与历练奇遇一样：可注入 `rollFn`，单测用 `() => 0` / `() => 0.99`。

```
chancePercent = clamp(3 + (fortune - 10) * 1.2, 1, 25)
triggered = (1d100 <= chancePercent)
```

仙缘 10 → 约 3%；仙缘 15 → 约 9%；上限 25%，避免气运满点场场神兵。  
未触发 = 失败档，不是「当没说过」。

## 4. 层 2 仍要防模型圆谎（骰完之后）

即使没走层 3：

- `item_changes` 里出现图鉴没有、背包没有的名字 → 丢掉，forcedOutcome 补「并无此物」。  
- `combat.outcome` 或伤害数字不采信，只采信 `resolveCombatModifiers`。  
- 玩家说「我已经金丹了」不改 `realm_major`。

这是第二道网：漏检的狂句最多变成「你这么想，天地不认」。

## 5. 其它「不合理」怎么归类（免得无限加 if）

| 类型 | 例子 | 归哪一层 |
|------|------|----------|
| 时空/身份不能同时 | 战中闭关、死人还行动 | 层 1 情境/死亡锁 |
| 宣称改存档数字 | 把修为改为 999 | 注入黑名单 |
| 宣称用没有的字典物 | 捏碎某张已登记符 | 物品熔断 |
| 宣称奇迹好运 | 捡神器反杀 | 层 3 封闭表 + 仙缘骰 |
| 普通胡话、玩笑、诗 | 我变成一只鸡 | **不拦截**；模型当戏言，数值不动 |
| 真要穷举社交/地理 | 「瞬移去中州」 | 以后 S31 赶路；未做前最多叙事、不改 `current_location` 到未邻接地点（地点表未接邻接前：可暂不改地点） |

原则：**只有「会改数值或发物品」的宣称才配代码。** 纯文戏让模型演，拦截器不给修为、不给神兵。

## 7. 验收（A5 / 层 3 落地时）

- `combat` 情境 + 「闭关」仍走情境锁 400，不进奇迹骰。  
- 「我发现绝世武器反杀」→ `detectMiracleClaim` 非空 → 必有一次注入 `rollFn` 的单测。  
- `rollFn` 使失败：无新物品，forcedOutcome 含落空。  
- `rollFn` 使成功：仍无新物品，forcedOutcome 含气运微澜且点明胜负以境界压制为准。  
- 敌高两境（用战斗公式测，不必在骰子函数里猜敌境）：无论骰子，结局仍秒杀。  
- 未点名神器/反杀的「再刺一剑」→ `detectMiracleClaim` 为 null，不掷本骰。  
- 子串「捡到剑」命中 loot；不得用正则 `捡到.*剑` 当唯一实现。
