## 1. 要解决的问题

修为攒满必须真的换境界：小境水到渠成，大境必须过雷劫骰。失败要伤、后期要能轰死，成功要抬寿元与气血上限。模型只能写雷声与心境，不能把人写飞升或写「无损结丹」。

玩家会试：一句话跳大境、结丹当金丹、渡劫期再点突破、战中破境、丹药替骰。天道只认当前键查表。

## 6. 结算 `resolveBreakthroughAttempt`

纯函数。随机必须可注入 `successRoll` / `deathRoll`（默认 `Math.random`）。`patch` 是 **终值覆盖**，不是增量。

自上而下只走一枝：

1. **无键**（`realmLaws[key]` 空）→ 失败；境界/气血/修为不变；`isMajorBreakthroughSuccess=false`。现码文案写「扣除少量灵力」但 **不改 mp**（加深改文案，见第 10 节）。
2. **修为不足**（低于 `reqCultivation`）→ 失败；`hp = clamp(hp-10, 0, maxHp)`；境界不变。
3. **`!isMajor`** → 成功；修为 0；写入 `next` 两段；气血与寿元不变；不掷骰。
4. **大境** → 先算成功率再掷 `successRoll`：
   - `roll <= successRate` → 成功：修为 0；`maxHp += maxHpGain`；`hp = 新 maxHp`；`maxLifespan = newLifespan`；`isMajorBreakthroughSuccess=true`（编排侧抽三天赋，**I26**）。
   - 否则先算陨落率，掷 `deathRoll`：命中 → `diedFromTribulation`；`hp=0`；境界不变。未命中 → 按上限百分比受伤、修为 `-100`（`applyCultivationDelta`，不低于 0）；寿元不变。

### 6.1 成功率

```
meritBonus = min(0.15, max(0, merit) * 0.0005)
successRate = clamp(baseSuccess + daoHeart * 0.01 + meritBonus, 0.05, 0.95)
```

功德约 300 点顶满 +15%。道心 10 → +0.10。禁止业力改本骰（业力走天罚，且本回合有突破则跳过天罚）。

成功判定：**`successRoll() <= successRate`**（骰到 `0` 且成功率大于 0 时必成）。

### 6.2 陨落率

```
deathChance = max(0, deathChanceOnFailure - daoHeart * 0.002)
```

仅当 `deathChance > 0` 且 `deathRoll() <= deathChance` 才轰灭。道心足够可把概率压到 0（单测：表内 0.5 时道心 250）。

**不**累计历史失败次数。功法、灵兽、伪装、仙缘骰 **不能** 改本骰，也不能取消事后的境界压制（A5 / I22）。

### 6.3 死因

渡劫轰灭 → `tribulation_failure`，优先于普通气血耗尽（I20 第 7.1 节）。轮回池：死后看 **结算后** 的 `realm_major` 是否 ≥ 筑基（`REALM_RANKS` ≥ 1）。炼气圆满失败未晋筑基 → 不入池；筑基后再死才入。大乘成功已是渡劫期再战死 → 入池。资格公式属 **I27**。
