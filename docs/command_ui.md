# 局内指令栏（功能规格 + 布局）

规格先行。14 个指令的**语义**在此拍死。电脑/手机分栏总图见 [ui.md](./ui.md)。窄屏底栏验收见 [mobile.md](./mobile.md)（I11，布局代码未做）。不改后端接口。

---

## 1. 要解决的问题

局内常驻入口原先只有约 104px 宽的竖条，全屏时右边日志很宽、左边指令挤成一条。需要：宽到一定程度后**左侧常驻打开人物面板**，指令排在面板**下面**、与面板同宽，按钮能并排，不再细条。

---

## 2. 十四指令（名字与顺序不可改）

`面板・修炼・突破・悟道・洞府・地图・背包・坊市・宗门・技艺・情缘・对话・存档・读档`

| 指令 | 行为 |
|------|------|
| 面板 | 打开人物详情。宽屏布局下面板已常驻，再点可不再弹层。 |
| 背包 / 洞府 / 宗门 / 情缘 | 弹详情窗，用已有数据，不调 DeepSeek |
| 修炼 | 发行动文本 `闭关修炼` |
| 突破 | `尝试突破境界` |
| 悟道 | `参悟道法` |
| 地图 | `查看九州地图` |
| 坊市 | `前往坊市` |
| 技艺 | `研习修仙百艺` |
| 对话 | `寻人交谈` |
| 存档 | 回存档列表（不调 action） |
| 读档 | 打开快照列表，可回滚 |

处理中 / 已死亡：行动类禁用；面板与背包/洞府/宗门/情缘、读档仍可开。

禁止汉堡菜单藏指令；禁止图标-only 无汉字。

---

## 3. 布局分档（宽度，不是「是否全屏」）

总图与电脑/手机对照见 [ui.md](./ui.md)。断点用 Tailwind：`lg` = **1024px**。

| 视口 | 布局 |
|------|------|
| **≥ 1024px（书房）** | 左侧约 420px：上人物面板常驻，下指令两列。右侧日志 + 输入。顶栏精简状态条可隐藏。 |
| **768～1023px（窄窗）** | 细竖条指令 + 右侧日志 + 顶栏状态条。I11 **不改**这一档。 |
| **&lt; 768px（掌中）** | I11 落地后：无左栏，指令底栏。见 [mobile.md](./mobile.md)。落地前与窄窗相同（细竖条，手机上会挤）。 |

「全屏」只是宽屏的一种情况，**以宽度为准**，不以是否最大化窗口为准。

---

## 4. 铁律

- 不改 `/api/action` 拦截器关键词；只改前端摆放。
- 主题色仍用 `bg-paper` / `border-jade` 等，无剧情 emoji。视觉总则 [ui.md](./ui.md)。
- 与 [game_design.md](./game_design.md) 指令行一致；改名字必须同步本表。

---

## 5. 验收

- 拉宽窗口过 1024px：左栏出现完整状态卡，其下指令为两列、明显宽于 104px。
- 缩到 768～1023：细竖条，日志仍可用。
- I11 后缩到 768 以下：底栏指令，无左栏。
- 宽屏点「修炼」「背包」语义与缩窄时相同；宽屏点「面板」不重复盖一层状态卡。
- `frontend` `npm run build` 过。
