# 局内指令（功能规格）

规格先行。本文件回答：**指令点下去会发生什么**。布局见 [ui.md](./ui.md)。代码见 [command_ui_architecture.md](./command_ui_architecture.md)。

菜单现为 **12 键**（已去掉「坊市」「对话」入口；买卖/交谈仍可在输入框手打）。

`面板・修炼・突破・悟道・洞府・地图・背包・宗门・技艺・情缘・存档・读档`

禁止汉堡里藏指令；禁止图标-only 无汉字。

---

## 1. 三类指令

| 类 | 指令 | DeepSeek | 改存档数值 |
|----|------|----------|------------|
| **只读** | 面板、背包、洞府、宗门、情缘、**地图**、**技艺** | **否** | 否 |
| **行动** | 修炼、突破、悟道 | 是（除非网关/情境锁/死亡先拒绝） | 由拦截器 + 公式 |
| **存档导航** | 存档、读档 | 存档否；读档只打快照接口 | 存档否；读档回滚改库，**不抹日志** |

---

## 2. 禁用规则

| 状态 | 只读七键 | 读档 / 存档 | 修炼·突破·悟道 + 输入框 |
|------|----------|-------------|-------------------------|
| 推演中 | 可点 | 可点 | 禁用 |
| 已死亡 | 可点 | 可点（读档可复活） | 禁用 |
| 天赋三选一未选 | 可点 | 可点 | 点了 `handleAction` 直接 return |

宽屏（≥1024）点「面板」：左栏已常驻，不再弹层。

---

## 3. 只读弹层（不调 `/api/action`）

| 指令 | 玩家看到 |
|------|----------|
| 面板 | 人物卡 |
| 背包 | 名 × 数量 |
| 洞府 | 有府：所在、等级、灵气。无府：尚无洞府（客栈不是府）。输入「开辟洞府」，或有宗门后称赐府。 |
| 宗门 | 宗名、职位、声望 |
| 情缘 | NPC、关系、好感 |
| **地图** | 宣纸示意图（金圈=所在）+ 短注。不改地点。赶路用手打。精细图待办 **I12**。 |
| **技艺** | 丹师/器师/阵师/灵植师，开局皆 **未习**（不是 1 级）。 |

---

## 4. 三条行动键（固定句 → `/api/action`）

| 指令 | `action` | 后端 |
|------|----------|------|
| 修炼 | `闭关修炼` | 情境锁；含「闭关」→ 未写年数则默认 1 年 |
| 突破 | `尝试突破境界` | 突破/雷劫 |
| 悟道 | `参悟道法` | 无专用拦截器 |

战中点「修炼」→ 400。见 [situation.md](./situation.md)。

---

## 5. 存档 / 读档与日志

| 指令 | 行为 |
|------|------|
| 存档 | 回存档列表。日志与**当前选项**写入本机 `localStorage`（按 `playerId`）。再进同一存档或刷新，历史行动与选项仍在。不是再拍快照。 |
| 读档 | 打开快照列表并回滚数值。日志**只追加**「时光倒流」一句。选项**不重置为开局三键**（快照未存选项，保留本机最后一组）。 |

日志最多保留约 400 条。换存档互不串。

---

## 6. 输入框

仍可手打前往坊市、寻人交谈、炼丹等。菜单不再提供这两键。

---

## 7. 验收

- 点「地图」「技艺」「背包」：网络里无 `/api/action`。
- 点「存档」回列表再进同一存档：日志还在，选项不是开局三键（若进局后曾更新过选项）。
- 刷新页面：同一 `playerId` 日志与选项还在。
- 读档成功：人物已回滚，日志未只剩一行，选项未变回预设三键。
- 无「坊市」「对话」按钮。
- `frontend` `npm run build` 过。
